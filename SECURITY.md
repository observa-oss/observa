# Security policy

Observa is in early development and nothing is deployed yet. We still welcome reports about the code and design in this repository.

## Reporting a vulnerability

Please do not report security issues in public GitHub issues, discussions or pull requests.

A dedicated private reporting channel will be set up and published here before Observa goes live. Until then, open a public issue titled "Security contact request" and leave out any details of the vulnerability. A maintainer will reply with a private way to share the report.

When you send the report, please include a description of the issue, steps to reproduce it, and the affected component or version if known.

## What to expect

- We aim to acknowledge reports within a few working days. Formal response times will be published before the service goes live.
- We will keep you informed while we investigate and fix the issue.
- We will credit reporters in the advisory unless they prefer not to be named.

## Supported versions

There are no releases yet. Once releases exist, this section will list which versions receive security fixes.
